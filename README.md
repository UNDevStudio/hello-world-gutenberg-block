# Hello World Gutenberg Block

A simple custom WordPress Gutenberg block built with JavaScript and `@wordpress/scripts`.

## Features

- Custom Gutenberg block
- Displays a "Hello World" placeholder
- Works in the WordPress block editor
- Renders on the WordPress front-end
- Built using the WordPress Scripts package

## Requirements

- WordPress
- Node.js and npm
- Local WordPress development environment
- VS Code

## Installation

1. Copy the `hello-world-block` folder into:

   `wp-content/plugins/`

2. Activate **Hello World Block** from the WordPress Plugins page.

3. Open the Gutenberg editor and search for the **Hello World** block.
